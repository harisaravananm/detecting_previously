📚 Research Summary — ML-T2-002
Central Research Question

"Can previously unseen malicious behaviour be identified from deviations in normal network behaviour?"

Approach

Autoencoder trained exclusively on BENIGN traffic. Attack flows produce high reconstruction error = anomaly signal.

Novel Attack Types Tested

Port Scan, DoS Slowloris, C2 Beacon, Data Exfiltration — none seen during training.

Key Differentiator

No class labels used in training. Detection is purely behavioural — deviation from learned normality.
